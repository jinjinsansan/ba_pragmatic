BOT SYSTEM
片側のみ稼働可（同時不可）。hh88はWS自動BET専用・通貨HKD。事前にhh88でライブバカラのマルチエリアを開いておくこと。
「betting Chromeで開く」を押すと 9222 Chrome に hh88 タブが開きます→ログイン→ライブバカラ→マルチエリア(multibaccarat)を開いてからSTART。
ONの間は v3/v4 のNOWが出たら本来の逆(B↔P)に自動BET。賭け・決済・光り・勝率は反転後で一貫します。エッジはありません（規律/手動代替用）。ON中は追従を自動停止します。切り忘れ防止のため再起動すると必ずOFFに戻ります（START都度ONにし直し）。
1-2-3打法の上げ方/戻り方をNハンド(=ターン制)=1セット単位で適用。セット内は固定額。負け越し→1→2→3(step3で更に負け越し→1へ一巡)・勝ち越し→1へ戻す。最大3単位＝絶対に破滅しない。
ダランベール(±1ユニット)をNハンド(=ターン制)=1セット単位で適用。セット内は固定額。負け越し→+1ユニット・勝ち越し→-1ユニット(下限1)。1-2-3より回収力が高いが上限なし＝連敗で青天井に増えるのでloss_cut（損切り）併用を強く推奨。
守備型ほど序盤を寝かせ天井を下げ、必要元本と全損リスクを下げる（利益は減る）。開始額に比例して適用。
比例(ケリー)では 攻撃=フルKelly / バランス=ハーフ / 守備=クォーター。守備推奨（複利・破滅せず・エッジ誤差に頑健）。
比例(ケリー)＝BET=残高×f。残高に比例するのでゼロにならない＝破滅しない・勝てば複利で増える。エッジ確実な6パターンで使うこと（v4では効かない）。攻撃型はDDが大きい（資産が一時7割減も）ので、まず守備型推奨。
切替時は進行中のセットを破棄して仕切り直し（負け越し・段位置は保持）。
達したら自動停止。SEQはリセットせず保持・利確額を表示したまま停止。再開(再起動)で続行(新セッション)。
セッション損失がこの額に達したら自動停止（飛ばない保険・どの資金管理モードでも有効）。0=無効。目安＝ユニット×300（例 $1なら$300・元本の約30%）。普段の谷では発動せず、稀な最悪の並びだけを止める。
